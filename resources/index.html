    Resources¶

    Core textbooks¶

    Book Chapters used
    Elmasri & Navathe, Fundamentals of Database Systems, 7th ed., Pearson, 2016 1–6, 14, 16, 17 (primary reference)
    Silberschatz, Korth & Sudarshan, Database System Concepts, 6th ed., McGraw-Hill, 2010 1–4, 6, 11 (secondary reference)
    Ramakrishnan & Gehrke, Database Management Systems, 3rd ed., McGraw-Hill, 2002 1–3, 5, 6, 19 (advanced reference)
    Garcia-Molina, Ullman & Widom, Database Systems: The Complete Book, 2nd ed., Pearson, 2008 1–5 (comprehensive reference)

    Free online resources 🆓¶

    • SQLBolt — sqlbolt.com — interactive SQL tutorial, perfect for the lab exercises.
    • PostgreSQL Documentation — postgresql.org/docs/ — free, authoritative, and the best reference for the DBMS used in the lab.
    • MySQL Documentation — dev.mysql.com/doc/ — alternative DBMS.
    • SQLite — sqlite.org — a lightweight embedded DBMS, ideal for learning SQL without setup overhead.
    • db-fiddle.com — db-fiddle.com — online SQL playground.
    • Stanford DB Course — online.stanford.edu/courses/soe-ydatabases — free introduction to databases.
    • CMU 15-445 — 15445.courses.cs.cmu.edu — database systems course with lecture videos and project specs.
    • use-the-index-luke.com — use-the-index-luke.com — excellent on indexing, hashing, and query performance.

    Software¶

    Tool Use
    PostgreSQL Primary DBMS for labs and project
    MySQL / MariaDB Alternative DBMS
    SQLite Lightweight, embedded
    pgAdmin / DBeaver GUI for database management
    draw.io / Lucidchart / DIA ER diagramming
    DataGrip / DBeaver SQL development environment
    EXPLAIN ANALYZE (PostgreSQL) Inspect query plans
    pg_stat_statements Query profiling

    Recommended first-week reading¶

    • Elmasri §1.1–§1.4 — the database approach vs. file-based systems.
    • Silberschatz §1.1–§1.3 — DBMS architecture and data models.
    • SQLBolt lessons 1–3 — start learning SQL early; the SQL chapter will be much easier with practice.
