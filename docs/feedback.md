# Feedback and Corrections

If you spot an error, a typo, or a broken link, please report it.

---

## What to report

| Category | Examples |
|---|---|
| Typo | Misspelled word, wrong symbol |
| Mathematical error | Wrong formula in a normalisation proof, incorrect cardinality |
| SQL error | Query that doesn't run on PostgreSQL |
| Broken link | 404 on a chapter or reference |
| Rendering problem | ER diagram not displaying |
| Clarity issue | Ambiguous definition, skipped mapping step |

---

## How to report

Open a GitHub issue at `github.com/YOUR-USERNAME/ECEG-4191/issues` with:

- Page path
- Section
- What is wrong
- What it should be
- Severity (typo / minor / major / blocking)

---

## Thank you

Every correction improves the course for the next cohort.
