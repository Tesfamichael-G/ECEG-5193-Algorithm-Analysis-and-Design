# Assessment

## Breakdown

| Component | Weight | Timing |
|---|:---:|---|
| **Project and Assignment** | **30%** | Assignments week 2, 4, 6, 7, 9, 10, 13, 14, 15; Project due week 17 |

---

## Assignments (part of the 30%)

Each assignment covers one chapter. Format: a PDF report plus source files (SQL scripts, ER diagram images).

| Criterion | Weight |
|---|:---:|
| Correctness of answers | 40% |
| Rigour of reasoning (normalisation, mapping) | 25% |
| Implementation (SQL, DDL) | 20% |
| Interpretation | 10% |
| Presentation | 5% |

**Late policy:** 10% per calendar day; zero after 3 days.

---

## Tests (30%)

Two tests, each 1.5 hours, closed book.

- **Test 1 (week 8, 15%)** — Chapters 1–3.
- **Test 2 (week 15, 15%)** — Chapters 4–5.

---

## Project (part of the 30%)

### Overview

A semester-long design-and-implementation project. Students work in **teams of 2–3**. The deliverables are:

| Deliverable | Week | Weight |
|---|:---:|:---:|
| Proposal (application domain, requirements) | 4 | 5% |
| ER/EER diagram | 8 | 15% |
| Relational schema + normalisation report | 12 | 20% |
| SQL implementation (DDL + sample queries) | 16 | 40% |
| Final report and demo | 17 | 20% |

### Project rubric

| Criterion | Weight |
|---|:---:|
| Completeness of requirements analysis | 15% |
| Correctness and clarity of ER/EER diagram | 20% |
| Correct mapping and normalization (≥ 3NF) | 25% |
| Working SQL implementation | 25% |
| Quality of report and demo | 15% |

**Suggested domains:** library management, hotel reservation, airline booking, hospital management, e-commerce, university registrar, bank branch, restaurant ordering.

### Submission

A single `.pdf` report plus a `.zip` bundle containing:

- The ER diagram source (draw.io / Lucidchart file).
- The SQL scripts (`schema.sql`, `data.sql`, `queries.sql`).
- A `README.md` explaining how to set up and run the database.

---

## Final examination (40%)

- **Format.** 3 hours, closed book.
- **Content.** Whole syllabus, weighted approximately as follows:

| Chapter | Weight |
|---|:---:|
| 1 Introduction | 8% |
| 2 Relational model | 10% |
| 3 ER modelling | 15% |
| 4 Logical design & normalisation | 25% |
| 5 Relational algebra & calculus | 15% |
| 6 SQL | 17% |
| 7 Storage & hashing | 10% |

- **Structure.** 6–8 questions mixing theory, ER drawing, mapping, normalization, and query writing.

## Academic integrity

All submitted work must be your own. Collaboration on *understanding* is encouraged; collaboration on *submitted answers* is plagiarism. Projects are group work, but each team's submission must be distinct.
