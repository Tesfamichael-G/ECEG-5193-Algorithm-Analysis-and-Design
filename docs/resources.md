## Free online resources 🆓

- **SQLBolt** — [sqlbolt.com](https://sqlbolt.com/) — interactive SQL tutorial, perfect for the lab exercises.
- **PostgreSQL Documentation** — [postgresql.org/docs/](https://www.postgresql.org/docs/) — free, authoritative, and the best reference for the DBMS used in the lab.
- **MySQL Documentation** — [dev.mysql.com/doc/](https://dev.mysql.com/doc/) — alternative DBMS.
- **SQLite** — [sqlite.org](https://www.sqlite.org/) — a lightweight embedded DBMS, ideal for learning SQL without setup overhead.
- **db-fiddle.com** — [db-fiddle.com](https://www.db-fiddle.com/) — online SQL playground.
- **Stanford DB Course** — [online.stanford.edu/courses/soe-ydatabases](https://online.stanford.edu/courses/soe-ydatabases) — free introduction to databases.
- **CMU 15-445** — [15445.courses.cs.cmu.edu](https://15445.courses.cs.cmu.edu/) — database systems course with lecture videos and project specs.
- **use-the-index-luke.com** — [use-the-index-luke.com](https://use-the-index-luke.com/) — excellent on indexing, hashing, and query performance.

## Recommended first-week reading

- **Elmasri §1.1–§1.4** — the database approach vs. file-based systems.
- **Silberschatz §1.1–§1.3** — DBMS architecture and data models.
- **SQLBolt lessons 1–3** — start learning SQL early; the SQL chapter will be much easier with practice.
